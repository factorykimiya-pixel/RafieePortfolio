# وب‌سایت مدیریتی محمد مهدی رفیعی

وب‌سایت شخصی فارسی/RTL برای معرفی سوابق مدیریتی، مجموعه کیمیا، برندهای کیمیا و پروشات، ظرفیت‌های تولیدی، آموزش فروش و فرصت‌های همکاری و سرمایه‌گذاری.

## اجرا

به **Node.js 20+** نیاز دارد.

```bash
npm ci
npm run dev
```

برای ساخت نسخه قابل انتشار:

```bash
npm run build
```

نسخه نهایی در پوشه `dist/` ساخته می‌شود. برای Vercel، مخزن را متصل کنید. Framework Preset = **Vite** ، Build Command = `npm run build` و Output Directory = `dist`.

## ویرایش محتوای سایت

- تمام متن‌ها، اعداد، برندها و مسیرهای تماس در `src/data/content.js` هستند.
- ساختار کارت‌ها و بخش‌ها در `src/sections/render.js` قرار دارد.
- رنگ‌ها در `tailwind.config.js` و سبک‌ها در `src/style.css` تعریف شده‌اند.
- تصاویر واقعی کارخانه و مدیرعامل در پوشه `public/` هستند.

### نکات ضروری پیش از انتشار

- ظرفیت اسمی ماهانه `۱۰۰٬۰۰۰` عدد، معادل `۴٬۰۰۰` عدد در روز **با فرض ۲۵ روز کاری** است؛ این عدد گزارش تولید محقق‌شده یا فروش نیست.
- چهار شماره در `profile.salesPhones` شماره‌هایی هستند که قبلاً برای **واحد فروش** اعلام شده‌اند. پیش از انتشار عمومی در سایت شخصی تأییدشان کنید.
- `profile.whatsappPhone` شماره پیش‌فرض آماده‌سازی پیام همکاری است. این فرم داده را ذخیره نمی‌کند و فقط واتساپ را با متن از پیش تکمیل‌شده باز می‌کند؛ ارسال نهایی به اقدام کاربر نیاز دارد.
- هیچ مبلغ سرمایه‌گذاری، سود، قیمت محصول، آمار فروش یا سابقه زمانی تأسیس شرکت بدون منبع اضافه نشده است.
- دامنه شخصی را پس از استقرار، در تنظیمات Vercel تعیین کنید.

## فناوری‌ها

Vite + Tailwind CSS + Vanilla JavaScript (بدون بک‌اند). حالت روشن/تاریک، منوی موبایل، افکت‌های اسکرول و محتوای ساختاریافته فارسی.

### انتشار روی GitHub و Vercel

۱. فایل ZIP را استخراج کنید و **محتویات پوشه `NewPortfolio-main`** را در ریشه مخزن GitHub قرار دهید (خود ZIP را به‌عنوان سورس آپلود نکنید).
۲. پروژه GitHub را در Vercel وارد کنید.
۳. Framework = `Vite` ، Build = `npm run build` و Output = `dist`.
۴. با هر Push به GitHub، در صورت فعال بودن اتصال، Vercel مجدداً سایت را منتشر می‌کند.

برای تست محلی، دستورات `npm ci` و `npm run dev` را اجرا کنید.
